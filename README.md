# Maze Escape (Godot)

A simple maze game created in Godot where the player navigates through three increasingly difficult maze levels to reach the exit. The game includes player movement with keyboard controls, wall collisions, a background, and a win screen after completing the final level.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download or clone this GitHub repository.
2. Open Godot Engine (version 4.x).
3. Click Import, select the project's `project.godot` file, and press F5 (or click Play) to run the game.

Instructions for using the software:

1. Use the arrow keys or WASD to move the player.
2. Navigate through each maze while avoiding the walls.
3. Reach the exit to advance to the next level until you complete all three levels.
